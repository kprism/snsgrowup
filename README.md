# SNSGROWUP

SNS 채널 통합 발행, 성장활동 관리, 성과분석, 신문사 RSS 기사 연동, AI 5초 쇼츠 제작을 제공하는 반응형 웹서비스입니다.

## 핵심 사용자

- 일반 계정 사용자: 직접 콘텐츠를 등록하고 SNS 채널을 성장·관리
- 신문사 사용자: SNS 기능과 함께 신문사 정보 및 RSS를 등록하고 기사 콘텐츠를 수집·배포

## 핵심 기능

1. 일반 사용자 / 신문사 사용자 분리 회원가입
2. Facebook, Instagram, YouTube, Threads 계정 연결
3. 관리자에서 SNS 플랫폼 종류 추가·관리
4. 일반 콘텐츠 작성 및 다중채널 발행
5. 신문사 RSS 등록, 검증, 기사 수집 및 중복 방지
6. 키워드 기반 성장 대상 탐색과 승인형 성장활동 관리
7. 채널별 팔로워·좋아요·조회수·증감 통계
8. 기사와 이미지 기반 AI 5초 YouTube Shorts 생성
9. 모바일 우선 반응형 PWA

## 개발 시작

GitHub Codespace를 만든 뒤 터미널에서 다음을 실행합니다.

```bash
bash scripts/bootstrap.sh
```
