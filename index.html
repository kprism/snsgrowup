콘텐츠를 만들고,
SNS 채널을 키우는 한곳.

페이스북·인스타그램·유튜브·쓰레드 계정을 연결하고, 콘텐츠 발행부터 성장활동, 성과분석, 신문사 RSS 기사 연동과 AI 5초 쇼츠 제작까지 통합 관리합니다.

🚀

일반 계정 사용자

개인·자영업자·크리에이터가 콘텐츠를 직접 등록하고 SNS 채널 연결, 발행, 성장활동과 성과분석을 관리합니다.

📰

신문사 사용자

신문사 정보와 RSS 주소를 등록하고 기사를 자동 수집해 여러 SNS 채널에 배포하며 AI 쇼츠로 재가공합니다.

핵심 기능

📡 SNS 계정 연결Facebook, Instagram, YouTube, Threads 채널을 한 계정에서 관리
✍️ 통합 콘텐츠 발행하나의 콘텐츠를 채널별 형식에 맞춰 다중 선택 발행
📈 성장 대시보드팔로워, 구독자, 좋아요, 조회수와 일별 증감 그래프
🎬 AI 5초 쇼츠기사 제목과 대표이미지를 활용해 짧은 세로형 영상을 자동 제작
📰 RSS 기사 수집신문사 RSS를 검증하고 기사 목록을 중복 없이 저장
🔎 성장 대상 탐색키워드 기반 관련 계정 후보와 순차 활동 흐름 제공
🧭 승인형 성장활동AI 추천 댓글과 활동 후보를 회원 또는 관리자가 확인 후 실행
📱 반응형 웹앱PC·태블릿·모바일에 최적화된 PWA형 인터페이스
현재 이 주소는 GitHub Pages에서 제공되는 화면 검토용 정적 홈입니다. 디자인과 구성은 계속 확인할 수 있지만, 실제 회원가입·로그인·RSS·DB 기능은 Django 서버에서 작동합니다.
